| 参数 | HDMI 2.1 | HDMI 2.0 |
| :--- | :--- | :--- |
| **差分阻抗** | 差分 100Ω ±10% | 100Ω ±10% |
| **差分对内等长** | < 6 mil | < 12 mil |
| **差分对间/与时钟等长** | < 480 mil（差分对间） | < 480 mil（时钟与数据间） |
| **最大走线长度** | **< 4 inches** (约 4000 mil) | **< 6000 mil** (约 6 inches) |
| **AC耦合电容** | 220nF ±20%，建议0201封装 | / |
| **数据信号间间距** | 建议 ≥ 7倍HDMI线宽 | 建议 ≥ 4倍线宽 |
| **数据/时钟信号间间距** | 建议 ≥ 7倍HDMI线宽（HDMI与其它信号） | 建议 ≥ 5倍线宽（HDMI数据与时钟间） |
| **过孔数量** | 建议不加过孔 | < 2个，并需在过孔旁加对称地孔 |
| **ESD保护器件要求** | I/O对地电容 ≤ 0.2pF | / |

- HDMI座子的焊盘和TVS管的焊盘的下方必须挖空一层来保证阻抗的连续性，挖空的大小，不小于封装焊盘尺寸
![alt text](/assets/images/硬件接口电路笔记/hdmi-layout-注意事项/PixPin_2025-10-21_13-55-09.png)

- HDMI的TVS管应尽量靠近连接座放置，信号拓扑为： HDMI座--->TVS--->CPU；出现ESD现象时，ESD电流必须先经过TVS器件衰减； TVS器件走线上不要有残桩(Stub)。 TVS的地管脚建议尽量增加地过孔，至少保证2个0.4*0.2mm的过孔，加强静电泄放能力
