## eDP 简介

eDP（Embedded DisplayPort）和 DP（DisplayPort）都是由 **VESA（视频电子标准协会）** 制定的数字显示接口标准，二者在技术上高度相关，但应用场景和优化方向有所不同。eDP 是 DP 的嵌入式版本。

### **1. 技术同源性**

- **eDP 基于 DP 协议**，核心信号传输机制（如数据包化、微片架构、MST 多流传输等）与 DP 一致。
- **共享物理层**：均采用 **差分信号（LVDS）** 传输，支持 **HBR（High Bit Rate）** 速率（如 HBR2、HBR3）。
- **版本同步**：eDP 通常跟随 DP 的版本更新（如 eDP 1.4 基于 DP 1.4）。

### **2. 主要区别**

| **特性**     | **DisplayPort（DP）**                | **eDP（Embedded DP）**                                          |
| ------------ | ------------------------------------ | --------------------------------------------------------------- |
| **应用场景** | 外部显示器（台式机、显示器、投影仪） | 内部显示屏（笔记本、平板、嵌入式设备）                          |
| **接口设计** | 标准插拔式接口（如 DP 20pin）        | 板对板连接（FPC 排线或焊接）                                    |
| **功耗优化** | 较少针对低功耗优化                   | 支持 **PSR（Panel Self Refresh）**、动态刷新率（Adaptive-Sync） |
| **功能扩展** | 支持多显示器（MST）                  | 可集成触摸、摄像头等辅助信号（AUX 通道）                        |
| **版本演进** | DP 1.2 → DP 1.4 → DP 2.0 → ...       | eDP 1.2 → eDP 1.4 → eDP 1.5 → ...                               |

---

### **3. 关键差异点**

**(1) 接口形式**

- **DP**：标准外部接口，使用 **20pin 插头**（如 DP、Mini DP）。
- **eDP**：无插头设计，通常通过 **FPC 柔性电路板** 直接连接主板和屏幕。

**(2) 功耗管理**

- **eDP 专为移动设备优化**，支持：
  - **PSR（Panel Self Refresh）**：静态画面时关闭 GPU 输出，仅由屏幕缓存维持显示，大幅降低功耗（适合笔记本续航）。
  - **动态刷新率（Adaptive-Sync）**：类似 FreeSync，减少画面撕裂并节能。

**(3) 信号集成**

- **eDP 可复用 AUX 通道** 传输触摸、摄像头等数据，减少额外布线。
- **DP 主要用于纯视频传输**，外设（如 USB、音频）需额外接口。

## eDP 主要线路

![eDP接口](/assets/images/硬件接口电路笔记/edp-概述/image.png)

- **主链路差分对 (`BNx`/`BPx`)**：决定了视频传输的带宽和数据量。
- **辅助通道对 (`AUXN`/`AUXP`)**：低速控制通道，负责通信和显示管理。
- **热插拔检测 (`HPD`)**：单线信号，报告显示器的物理连接状态。
- **电源 (`VCC3S`)** 和 **接地 (`GND`)**

主链路和辅助通道，都使用0.1uF电容耦合，且都需要TVS保护。
