## 1. 四种常见电阻类型及典型代表  

### 1.1 薄膜电阻  
- **原理**：在绝缘基板上沉积导电薄膜（如碳、金属或金属氧化物），通过刻蚀调整阻值。  
- **特点**：体积小、精度较高、稳定性好。  
- **典型电阻**：碳膜电阻、金属膜电阻、金属氧化膜电阻、玻璃釉电阻。  

### 1.2 线绕电阻  
- **原理**：用合金电阻丝（如镍铬、康铜）绕在陶瓷或塑料骨架上制成。  
- **特点**：功率大、耐高温、精度高，但高频性能较差。  
- **典型电阻**：功率线绕电阻、精密线绕电阻、高频线绕电阻。  

### 1.3 实心电阻  
- **原理**：由导电材料（如碳粉）和粘合剂混合压制而成。  
- **特点**：结构简单、成本低，但稳定性较差。  
- **典型电阻**：碳质实心电阻、有机实心电阻。  

### 1.4 特种电阻（敏感电阻）  
- **原理**：电阻值随外界环境（如温度、光、压力等）变化。  
- **特点**：用于检测或控制特定物理量。  
- **典型电阻**：热敏电阻、光敏电阻、压敏电阻、湿敏电阻、气敏电阻。

## 3. 阻值表示法  

### 3.1 核心标准系列  
- **E24 系列**（±5% 精度）  
- **E48 系列**（±2% 精度）  
- **E96 系列**（±1% 精度）  
- **E192 系列**（±0.5% 精度）  

---

### 3.2 编码规则详解  

| 系列      | 编码位数 | 结构说明                     | 示例及解析                  | 特殊表示法          |
|-----------|----------|------------------------------|-----------------------------|---------------------|
| **E24**   | 3位字符  | `AB`=有效数字，`C`=零的个数   | ▶ 102 = 10×10² = 1kΩ        | 9R1 = 9.1Ω           |
|           |          |                              | ▶ 105 = 10×10⁵ = 1MΩ        | （R = 小数点）       |
| **E96**   | 4位字符  | `ABC`=有效数字，`D`=零的个数  | ▶ 1542 = 154×10² = 15.4kΩ   | 10R0 = 10.0Ω         |
|           |          |                              | ▶ 4990 = 499×10⁰ = 499Ω     | （R = 小数点）       |
| **E96**   | 3位字符  | `XY`=E96序号，`Z`=10的幂次   | ▶ 01A = 100×10⁰ = 100Ω      | 需查 E96 代码表      |
|           |          | （需查代码表）               | ▶ 24C = 165×10² = 16.5kΩ    |                     |

---

### 3.3 关键要点对比  

1. **小数点规则**  
   - E24：`R` 用于 <10Ω（如 `2R7 = 2.7Ω`）  
   - E96：`R` 用于 <100Ω（如 `49R9 = 49.9Ω`）  

2. **有效数字精度**  
   - E24：仅支持 2 位有效数字（10~91）  
   - E96：支持 3 位有效数字（100~976）  

3. **E96 三位码速查**  
   - 代码 `01` → 阻值 100  
   - 代码 `24` → 阻值 165  
   - 代码 `96` → 阻值 976  
   - （完整表见标准文档）  

---

### 3.4 典型应用场景  

- **E24**：普通消费电子产品（如充电器、玩具）  
- **E96**：精密仪器、医疗设备、通信模块  
- **E192**：高频电路、航天级设备
