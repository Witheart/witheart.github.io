概要：本文详细介绍了在Ubuntu系统中安装和使用todesk及向日葵远程控制软件的完整流程，包括安装步骤、启动方法和注意事项。 


## 0. 安装包准备
向日葵官方没有提供标准的arm64软件包，使用麒麟系统版本代替：
[https://sunlogin.oray.com/download/linux?type=personal](https://sunlogin.oray.com/download/linux?type=personal)

## 1. 安装准备  

1.1 进入安装包所在目录  
通常deb安装包存放在用户主目录下，使用以下命令进入：  
```bash
cd /home/user
```  
> 注：实际路径请根据安装包存放位置调整  

---

## 2. 安装todesk    
使用apt安装todesk的deb包：  
```bash
apt install ./todesk-v4.7.2.0-arm64.deb
```  
> 注：文件名需根据实际安装包名称修改  

---

## 3. 安装向日葵  
使用apt安装向日葵的deb包：  
```bash
apt install ./SunloginClient_11.0.1.44968_kylin_arm.deb
```  
> 注：文件名需根据实际安装包名称修改  

---

## 4. 使用方法  

### 4.1 启动todesk  
在桌面状态下打开终端，输入以下命令启动：  
```bash
todesk
```  

### 4.2 启动向日葵  
在桌面状态下打开终端，通过完整路径启动向日葵客户端：  
```bash
/usr/local/sunlogin/bin/sunloginclient
```
