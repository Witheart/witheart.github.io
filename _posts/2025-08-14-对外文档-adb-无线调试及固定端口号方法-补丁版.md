## 1. ADB 无线调试流程  

### 1.1 设备说明  

- **主机**：运行 ADB 并用于调试的电脑  
- **目标板**：被调试的设备  

**要求**：主机和目标板需连接同一局域网，并且目标板通过 Wi-Fi 连接到该局域网。  

### 1.2 开启无线调试  

1. **进入设置 -> 无线调试**，点击打开无线调试选项。  
   ![无线调试选项](/assets/images/对外文档/adb-无线调试及固定端口号方法-补丁版/image.png)  

2. **获取目标板 IP 地址**  
   - 路径：**设置 -> 关于平板电脑 -> IP 地址**  
   - 记录下 IP 地址，例如 `192.168.0.189`。  
   ![IP地址](/assets/images/对外文档/adb-无线调试及固定端口号方法-补丁版/image-1.png)  

3. **主机进入 ADB 工具文件夹**  
   - 在 ADB 工具文件夹路径下打开命令行（cmd）。  

![alt text](/assets/images/对外文档/adb-无线调试及固定端口号方法-补丁版/PixPin_2025-07-09_15-05-28.png)
### 1.3 连接目标板  

1. **使用 ADB 连接目标板**  

   ```sh
   adb connect 目标板IP地址:5555
   ```

   例如：  

   ```sh
   adb connect 192.168.0.189:5555
   ```

   **成功连接后**，会显示：  

   ```sh
   connected to 192.168.0.189:5555
   ```

2. **指定端口号**  

   ```sh
   adb tcpip 5555
   ```

3. **查看已连接的 ADB 设备**  

   ```sh
   adb devices
   ```

   **输出示例**：  

   ```sh
   List of devices attached
   192.168.0.189:5555      device
   ```

4. **进入 ADB Shell 进行调试**  

   ```sh
   adb shell
   ```

## 2. 常见问题及解决方案  

### 2.1 连接失败的解决方法  

如果执行 `adb connect 目标板IP地址:5555` 后出现以下错误：  

```sh
cannot connect to 目标板IP:5555: 由于连接方在一段时间后没有正确答复或连接的主机没有反应，连接尝试失败。(10060)
```

请按照以下步骤排查：  

1. **检查目标板 IP 地址是否正确**。  
2. **尝试使用 USB 连接 ADB 进行调试**，然后重新指定端口号：  

   ```sh
   adb tcpip 5555
   ```

3. **拔掉 USB 连接后，重试无线调试**。
