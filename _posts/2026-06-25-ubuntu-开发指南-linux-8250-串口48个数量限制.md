## 问题
Linux 8250 串口子系统，在编译时指定了串口数量的限制，一般是48个，导致K3服务器（48个K3串口+1个BMC串口）的串口无法全部探测出来。

## 排查
- 使用这个命令可以查看8250的串口数量限制
```bash
cat /boot/config-$(uname -r) | grep CONFIG_SERIAL_8250_NR_UARTS
```
输出

```bash
CONFIG_SERIAL_8250_NR_UARTS=48
```
可以看到，限制为48个。

而厂家提供的串口驱动，也是调用了8250的函数了，所以也受此限制影响。
