下文以“新建Ubuntu开发目录”为例。

## 目标结构
```
新建Ubuntu开发目录
    00_需求/
        需求.md
    01_image/
        00_测试用update/
            来源.txt
        01_修改用update/
            来源.txt
        02_修改后rootfs/
        03_基于02的update/
    02_资料/
    03_log/
    04_编译出文件/
```

## 创建批处理脚本：
编码需要和系统一致，下面脚本应该保存为GB2312，实测其他编码有bug。
```bat
@echo off
chcp 936 >nul

set "root=新建Ubuntu开发目录"
if exist "%root%" (
    echo 目录已存在，按任意键退出
    pause >nul
    exit /b
)

:: 创建根目录
md "%root%"
cd /d "%root%" || exit /b

:: 创建一级目录
md "00_需求" "01_image" "02_资料" "03_log" "04_编译出文件"

:: 创建二级目录（在01_image下）
cd "01_image"
md "00_测试用update" "01_修改用update" "02_修改后rootfs" "03_基于02的update"
cd ..

:: 创建空文件（使用绝对路径）
type nul > "00_需求\需求.md"
type nul > "01_image\00_测试用update\来源.txt"
type nul > "01_image\01_修改用update\来源.txt"

echo 目录结构创建完成！
timeout /t 1 >nul
```

## 注册表设置方法：
- Win+R 输入 `regedit` 打开注册表
- 定位到：
`HKEY_CLASSES_ROOT\Directory\Background\shell`

- 新建项命名为 `CreateUbuntuDevDir`
- 在右侧修改默认值为 `创建Ubuntu开发目录`
- 在CreateUbuntuDevDir下新建项命名为 `command`
- 修改command的默认值为：
`"C:\Windows\System32\cmd.exe" /c "完整路径\create_ubuntu_dir.bat"`

### 注意
• 将脚本保存为 create_ubuntu_dir.bat
• 放在无空格路径如 `C:\Scripts\`
• 需要管理员权限运行时，可创建快捷方式并设置"以管理员身份运行"

### 效果：
在任意文件夹空白处右键 -> 选择"创建Ubuntu开发目录"，即可自动生成完整空目录结构。

## 删除
如需删除该右键菜单：
1) 删除注册表项 `HKEY_CLASSES_ROOT\Directory\Background\shell\CreateUbuntuDevDir`
2) 删除脚本文件即可
