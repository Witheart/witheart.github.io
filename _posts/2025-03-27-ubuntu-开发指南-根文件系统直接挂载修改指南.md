## 1. 挂载 `rootfs.ext4`
### 方法 1：直接挂载（适用于 Linux）
```bash
# 创建挂载点
sudo mkdir -p /mnt/rootfs

# 挂载 ext4 镜像（使用 loop 设备）
sudo mount -o loop rootfs.ext4 /mnt/rootfs
```

---

## 2. 修改内容
- 直接操作挂载点 `/mnt/rootfs`：
  ```bash
  sudo nano /mnt/rootfs/etc/fstab  # 示例：编辑配置文件
  sudo cp ~/custom-file /mnt/rootfs/home/  # 复制文件
  sudo chroot /mnt/rootfs  # 如果需要 chroot 环境
  ```

---

## 3. 保存修改
### 正确卸载以写入更改
```bash
# 直接卸载
sudo umount /mnt/rootfs
```
- 关键点：
  - 确保没有进程占用挂载点（如 `lsof /mnt/rootfs`）。
  - 卸载后，所有修改会自动写入 `rootfs.ext4` 镜像。
