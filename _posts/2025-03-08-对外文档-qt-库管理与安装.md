概要：本文介绍了系统中 Qt 库的两个版本位置，以及如何使用 `update-alternatives` 管理默认 `qmake` 版本。同时，还提供了源码位置和安装参数信息。  


## 1. Qt 版本位置  

系统中存在两个 Qt 版本：  

- **版本 1**：位于 `/opt/Qt5.14.2/`  
- **版本 2**：位于系统默认路径 `/lib/aarch64-linux-gnu/` 或 `/usr/lib/aarch64-linux-gnu/`  

---

## 2. 默认 `qmake` 版本管理  

可以使用 `update-alternatives` 管理默认 `qmake` 版本：  

```sh
sudo update-alternatives --config qmake
```

执行后，系统显示以下可选项：  

```sh
有 2 个候选项可用于替换 qmake (提供 /usr/bin/qmake)。

  选择       路径                                    优先级  状态
------------------------------------------------------------
* 0            /opt/Qt5.14.2/bin/qmake                    100       自动模式
  1            /opt/Qt5.14.2/bin/qmake                    100       手动模式
  2            /usr/lib/aarch64-linux-gnu/qt5/bin/qmake   50        手动模式

要维持当前值[*]请按<回车键>，或者键入选择的编号：
```

- 当前默认 `qmake` 版本为 `/opt/Qt5.14.2/bin/qmake`（自动模式）。  
- 如果需要切换版本，可以输入相应的编号进行选择。  

---

## 3. Qt 源码位置  

Qt 源码存放于：  

```sh
/root/Qt-5.14.2/qt-everywhere-src-5.14.2/
```

---

## 4. Qt 安装参数  

安装 Qt 时，使用的是以下 `configure` 命令：  

```sh
./configure -prefix /opt/Qt5.14.2 -opensource -confirm-license -release \
  -nomake examples -nomake tests -no-openssl -no-icu \
  -skip qtlocation
```

### **参数说明**：  
- `-prefix /opt/Qt5.14.2`：指定安装路径。  
- `-opensource -confirm-license`：使用开源许可并自动确认许可协议。  
- `-release`：编译发布版本，而非调试版本。  
- `-nomake examples -nomake tests`：不编译示例和测试代码，减少编译时间。  
- `-no-openssl -no-icu`：不使用 OpenSSL 和 ICU。  
- `-skip qtlocation`：跳过 `qtlocation` 模块的编译。
