**QEMU** 是一款开源的**硬件虚拟化模拟器**，它允许你在一个操作系统上运行另一个操作系统的程序，甚至模拟完整的计算机系统（包括 CPU、内存、存储设备、外设等）。
简单来说，QEMU 就像一个“计算机的乐高”，可以用软件“拼”出一台虚拟的电脑。


### 核心特性与工作原理

1. **系统模式**  
   模拟完整的计算机硬件（CPU、内存、主板、磁盘等），可以在此虚拟机上安装和运行完整的操作系统。例如，在 Linux 上虚拟运行 Windows。

2. **用户模式**  
   仅模拟 CPU 指令集，用于跨平台运行单个程序。例如，在 x86 电脑上运行为 ARM 架构编译的程序。

3. **动态二进制翻译**  
   QEMU 的核心技术。它将目标架构（如 ARM）的 CPU 指令实时翻译成宿主架构（如 x86）的指令，从而实现跨平台运行。

4. **设备模拟**  
   支持模拟多种硬件设备：硬盘、网卡、USB 控制器、显卡等，使虚拟机具备完整的硬件功能。

### 常见应用场景

- **跨平台开发与测试**  
  开发者可在个人电脑（如 x86）上测试为其他架构（如 ARM、RISC-V）编写的程序。

- **嵌入式开发**  
  在没有实体硬件时，用 QEMU 模拟开发板（如树莓派）进行系统调试。

- **虚拟化**  
  结合 KVM（Linux 内核虚拟化模块）实现高性能虚拟化，是许多云计算平台（如 OpenStack）的底层技术。

- **安全研究**  
  在隔离的虚拟环境中分析恶意软件或测试系统漏洞。

- **旧系统兼容**  
  运行已停产硬件（如经典游戏主机）的软件。

### 与常见虚拟化工具对比

| 工具                  | 类型           | 特点                                                  |
| --------------------- | -------------- | ----------------------------------------------------- |
| **QEMU**              | 模拟器+虚拟化  | 支持多架构，纯软件模拟速度较慢，配合 KVM 性能接近原生 |
| **VMware/VirtualBox** | 虚拟化软件     | 仅支持 x86 架构，依赖宿主 CPU 虚拟化扩展，性能较好    |
| **KVM**               | 内核虚拟化模块 | 需配合 QEMU 使用，提供 CPU 虚拟化加速                 |
