概要：本文介绍如何通过命令行方式自定义系统启动时显示的 Logo，包括准备 BMP 格式图片、挂载分区并替换 Logo 文件的具体步骤。适用于需要个性化设备开机画面的用户。


## 1. 准备工作  

### 1.1 准备 Logo 图片  

- **格式要求**：必须为 BMP 格式，位深为 24 位（使用 32 位会出现上下左右显示镜像的问题）  
- **分辨率**：应与设备显示分辨率一致  
- **数量要求**：  
  准备一张图片，复制两份并分别命名为：  
  - `logo.bmp`  
  - `logo_kernel.bmp`  

### 1.2 存储设备准备  

- 将准备好的 Logo 图片存入 U 盘或 TF 卡中  

> 注意：由于分区挂载目录所有者为 root，以下操作必须使用 root 权限  

切换为 root 用户：

```bash
sudo su
```

使用 lsblk 查看 mmcblk2p7 的挂载位置：

```bash
root@user:~# lsblk
NAME         MAJ:MIN RM  SIZE RO TYPE MOUNTPOINT
sda            8:0    1  7.5G  0 disk
└─sda1         8:1    1  7.5G  0 part /media/user/3
mmcblk2      179:0    0 29.1G  0 disk
├─mmcblk2p1  179:1    0    4M  0 part
├─mmcblk2p2  179:2    0    4M  0 part
├─mmcblk2p3  179:3    0    4M  0 part
├─mmcblk2p4  179:4    0   64M  0 part
├─mmcblk2p5  179:5    0   64M  0 part
├─mmcblk2p6  179:6    0   32M  0 part
├─mmcblk2p7  179:7    0   64M  0 part /media/user/791a7548-4cfd-4e5d-bc09-aa146be293291
└─mmcblk2p8  179:8    0 28.9G  0 part /
mmcblk2boot0 179:32   0    4M  1 disk
mmcblk2boot1 179:64   0    4M  1 disk
```

可以看到挂载位置为：

```
/media/user/791a7548-4cfd-4e5d-bc09-aa146be293291
```

如果未挂载，则手动挂载即可，方式如下：

创建挂载点
```bash
mkdir -p /media/user/logo
```

挂载
```bash
mount /dev/mmcblk2p7 /media/user/logo
```

---

## 2. 替换 Logo 文件  

### 2.1 挂载 U 盘路径  

插入 U 盘后，再次输入 lsblk 命令，查看其挂载路径。

进入 U 盘路径，例如：

```bash
cd /media/user/YourUSBMountPath
```

### 2.2 替换 Logo 图片  

将准备好的图片复制到目标挂载目录：

```bash
cp logo.bmp /media/user/791a7548-4cfd-4e5d-bc09-aa146be293291
cp logo_kernel.bmp /media/user/791a7548-4cfd-4e5d-bc09-aa146be293291
```

---

## 3. 重启设备并查看效果  

执行以下命令重启设备：

```bash
reboot
```

设备重启后，即可查看自定义 Logo 显示效果。
