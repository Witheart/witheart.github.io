概要：本指南记录了如何将已在 A 主机（RK3588 Ubuntu）上编译完成的 Qt5.14.2 库移植到 B 主机（另一台 RK3588 Ubuntu），包括打包、解压及必要的依赖安装步骤。  


## 1. 在 A 主机上打包 Qt 库  

首先，在 A 主机上对已安装的 Qt5.14.2 进行打包：  

```bash
cd /opt  
sudo tar -czvf Qt5.14.2.tar.gz Qt5.14.2/
```

---

## 2. 在 B 主机上安装 Qt 库  

### 2.1 解压 Qt 库  

在 B 主机的 `/opt` 目录下解压 Qt5.14.2：  

```bash
cd /opt  
sudo tar -xzvf Qt5.14.2.tar.gz  
```

### 2.2 更新系统软件包  

```bash
sudo apt update  
```

### 2.3 安装必要的依赖  

运行以下命令安装 Qt 运行所需的依赖库：  

```bash
sudo apt install build-essential libgl1-mesa-dev libxkbcommon-dev libxkbcommon-x11-dev \
libxcb-xinerama0-dev libxcb-xinerama0 libxcb-icccm4-dev libxcb-image0-dev \
libxcb-keysyms1-dev libxcb-render-util0-dev libxcb-shape0-dev libxcb-sync-dev \
libxcb-xfixes0-dev libxcb-xkb-dev libxcb1-dev libxcb1 libxrender-dev libx11-dev \
libx11-xcb-dev libxi-dev libxext-dev libfontconfig1-dev libfreetype6-dev libpng-dev \
libjpeg-dev libssl-dev libdbus-1-dev libicu-dev libpulse-dev libasound2-dev \
libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev
```

此外，还需要安装 Python 和 Wayland 相关库：  

```bash
sudo apt install python  
sudo apt install libwayland-dev  
```

### 2.4 配置 `qmake` 版本管理  

使用 `update-alternatives` 配置 `qmake`，确保系统优先使用 `/opt/Qt5.14.2/bin/qmake`：  

```bash
sudo update-alternatives --install /usr/bin/qmake qmake /opt/Qt5.14.2/bin/qmake 100  
sudo update-alternatives --install /usr/bin/qmake qmake /usr/lib/qt5/bin/qmake 50  
```

### 2.5 添加环境变量
添加到要配置的账户的~/.bashrc
```bash
export PATH="/opt/Qt5.15.2/bin:$PATH"
export QTDIR=/opt/Qt5.15.2
#export LD_LIBRARY_PATH="/opt/Qt5.15.2/lib:$LD_LIBRARY_PATH"
# 动态链接库在 /etc/ld.so.conf.d/aarch64-linux-gnu.conf 下定义
export PKG_CONFIG_PATH="/opt/Qt5.15.2/lib/pkgconfig:$PKG_CONFIG_PATH"
```
编辑/etc/ld.so.conf.d/aarch64-linux-gnu.conf
加入
```bash
/opt/Qt5.15.2/lib:$LD_LIBRARY_PATH
```

---

可以使用 `update-alternatives` 管理默认 `qmake` 版本：  

```sh
sudo update-alternatives --config qmake
```

### 2.6 更新动态链接库路径
```sh
# 创建配置文件
sudo sh -c 'echo "/opt/Qt5.15.2/lib" > /etc/ld.so.conf.d/qt5.conf'

# 更新库缓存
sudo ldconfig

# 验证
ldconfig -p | grep Qt5
```
