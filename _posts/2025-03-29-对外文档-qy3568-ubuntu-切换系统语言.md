本指南将帮助您在 Ubuntu 系统中安装和使用 language-switcher 工具来更改系统语言。


## 安装步骤

### 准备工作
1. 复制 language-switcher.deb 安装包到系统中
2. 确保已连接到互联网

### 安装过程
1. 打开终端（快捷键：Ctrl+Alt+T）
2. 导航到安装包所在目录：
3. 更新软件源（需要管理员权限）：
   ```bash
   sudo apt update
   ```
4. 安装 language-switcher 工具：
   ```bash
   sudo apt install ./language-switcher.deb -y
   ```

## 使用方法

### 切换系统语言
1. 点击切换语言选项
![alt text](/assets/images/对外文档/qy3568-ubuntu-切换系统语言/image.png)
![alt text](/assets/images/对外文档/qy3568-ubuntu-切换系统语言/image-1.png)

2. 按照提示进行切换
![alt text](/assets/images/对外文档/qy3568-ubuntu-切换系统语言/image-2.png)

3. 切换完成后重启即可
