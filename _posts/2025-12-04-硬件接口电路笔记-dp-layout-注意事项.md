- RK官方对DP1.4的 layout 要求如下

| 参数 | 要求 |
| :--- | :--- |
| **走线阻抗** | 差分 100Ω ±10% (仅作为DP接口，无复用)<br>差分 95Ω ±10% (USB3.0 / DP1.4 复用) |
| **差分对内时延差** | < 6 mil |
| **差分对间等长要求** | < 1000 mil |
| **走线长度** | < 6 inches |
| **差分对间间距 (airgap)** | 建议 ≥ 6倍DP线宽 |
| **DP与其它信号间距 (airgap)** | 建议 ≥ 6倍DP线宽 |
| **各信号所允许过孔数量** | 建议不超过 2 个 |
| **电容要求** | 建议 100nF (容值范围 75nF ~ 200nF) |
| **ESD** | I/O对地电容不超过 0.2pF |

建议在 BGA 区域的以下位置加地通孔，并作包地处理，包地线的地孔间隔小于 300mil。
