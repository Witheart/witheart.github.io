概要：由于存储空间不足，Gitblit 从 `/home/arm/work/gitblit-1.9.1/` 移至 `/mnt/nvme/gitblit-1.9.1/`，并进行了相应的配置修改和备份操作。  


## 1. Gitblit 迁移步骤  

### 1.1 修改启动参数  
在 `/etc/ec.local` 中修改启动参数，调整 `gitblit.sh` 位置：  
- **新路径**：`/mnt/nvme/gitblit-1.9.1/gitblit.sh`  
- **修改 ext 路径**  

### 1.2 预启动 Gitblit  
在 Gitblit 根目录下执行以下命令：  
```sh
sudo java -cp "gitblit.jar:ext/*" com.gitblit.GitBlitServer --baseFolder data
```
执行后启动 Gitblit，查看 web 服务是否生效，然后退出。  

---

## 2. 备份与清理  

### 2.1 备份原 Gitblit 目录  
将原 `/home/arm/work/gitblit-1.9.1/` 目录备份至：  
```sh
/mnt/hdd/gitblit-1.9.1-250307-backup.tar.gz
```

### 2.2 删除原目录  
删除旧的 Gitblit 目录：  
```sh
rm -rf /home/arm/work/gitblit-1.9.1/
```

---

## 3. 迁移完成与生效  
重启系统后，新的 Gitblit 位置生效，迁移完成。
