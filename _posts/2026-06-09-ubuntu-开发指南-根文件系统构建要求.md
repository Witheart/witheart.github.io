## 简介

构建适用于 RK3568（基于 ARM64 架构）的 Ubuntu 根文件系统，最主流且高效的方法是使用官方的 Ubuntu Base 镜像，配合主机（通常是 x86 架构的 PC）上的 qemu-user-static 工具，通过 chroot 的方式进行模拟构建。

## 一、 系统要求

**1. 基础系统与环境配置**

- sudo unminimize
- LightDM+XFCE
- root用户+user普通用户
- 中文系统（语言支持（policykit修复）+右键菜单等修复）
- apt镜像源替换国内源
- 加入版本查看
- SN读取功能（/usr/local/bin/sn_read-HUIWAN）
- 开机logo分区名称修改
- 关闭休眠
  - XFCE：电源管理器
  - GNOME：
    - 设置-隐私-锁屏-自动锁屏 -> 关闭
    - 设置-电源-无操作时屏幕变暗 -> 关闭
- 关闭系统自动更新（软件和更新中，“自动检查更新”设置为从不、“有新版本时通知我”设置为从不）
- user 加入组adm,disk,dialout,cdrom,sudo,audio,dip,video,plugdev,staff,systemd-journal,bluetooth,netdev,pulse-access,lpadmin

**2. 登录与安全权限**

- 开机自动选择XFCE会话，并登录普通用户桌面
- 去除密钥环
- 安装policykit但去除policy认证

**3. 桌面UI与交互体验**

- 中文输入法ibus+rime
- 关闭panel工作区，以及显示管理器微调中关闭滚轮切换工作区
- 缩略图显示
- 在此处打开终端
- 时间显示格式
- 截图功能+截图窗口大小修复
- 更换桌面壁纸
- 解决vim 中文字符显示异常的问题（配置utf-8）
- 更改panel时间显示格式%Y-%m-%d %H:%M

**4. 网络与远程连接**

- 解决nmcli 默认不管理有线网络问题（创建空文件/etc/NetworkManager/conf.d/10-globally-managed-devices.conf）
- 网络配置DHCP
- 网络配置优先级：有线>wifi>移动网络
- 正确的DNS配置
- SSH欢迎信息修改（/etc/update-motd.d/00-header）
- 允许root登录SSH
- 关闭WiFi省电，规避WiFi省电无法唤醒导致的网络崩溃问题

**5. 调试与日志管理**

- debug串口自动登录（/etc/systemd/system/serial-getty@.service.d/override.conf）
- debug串口自动输出调试日志级别修改（开机脚本配置echo "8 4 1 7" > /proc/sys/kernel/printk）
- 日志记录，日志大小限制

**6. 存储与外设**

- 支持各种格式U盘
- u盘开机自动挂载

**7. 自动化与系统控制**

- 自动校时+ntp复位相关
- 开机脚本
  - wifi/bt
  - 根文件系统扩展 /usr/local/bin/resize-rootfs.sh
- 开机次数计数脚本，自动重启功能

**8. 预置应用与测试工具**

- xfce4-goodies
- nano
- 串口软件cutecom
- 预置todesk安装包
- 浏览器及浏览器硬件加速
- 预置各类压缩软件（zip unzip unrar p7zip-full）
- 预置相机软件（cheese）
- 预置图片查看器（ristretto）
- 预置文本编辑软件（gedit）
- 预置htop
- stress
- stress-ng
- 编译安装stressapptest
- lm-sensors
- 预置CSV数据显示软件（gnumeric）
- i2c工具（i2c-tools）
- can工具（can-utils）
- iperf3
- tcpdump
- minicom
- rsync
- curl & wget
- build-essential
- git
- fio
- sysstat
- iotop（CONFIG_TASKSTATS, CONFIG_TASK_DELAY_ACCT, CONFIG_TASK_IO_ACCOUNTING）
- toilet figlet
- gnome-sound-recorder
- vlc
- ubuntu-restricted-extras libavcodec-extra ffmpeg
- python3-pip
- pip3 install pyserial
- exfat(exfat-fuse exfat-utils)
- ntfs(ntfs-3g)
- U按自动挂载(udiskie)
- onboard
- lsusb(usbutils)
- lspci(pciutils)
- strace
- system profiles and benchmark(hardinfo)

**9. 固件与底层刷写**

- 在线刷写屏参
- 在线刷写boot功能

**10. 测试资源**
- 预置测试资源：
  - mp3 wav
  - png jpg
  - mp4
  - csv

## 二、 接口

- wifi/bt功能
  - 开机脚本加载WiFi和蓝牙
  - 部署/usr/local/bin/setup_wifi_firmware.sh
  - /root下加入BCM43430_nm372.hcd  BCM43455_cm256.hcd  dhd-cyw43430.ko
  - /vendor/etc/firmware下加入 cyw43438_azw372.txt  cyw43438.bin  cyw43455_azw256.txt  cyw43455.bin
- gpio测试脚本，信息查询脚本
- uart测试脚本
- 声音播放，声音配置自动保存
- 麦克风输入
