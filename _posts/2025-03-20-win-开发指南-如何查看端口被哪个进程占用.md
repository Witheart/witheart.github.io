概要：本文介绍了在 Windows 系统中查看特定端口（如 53317）被哪个进程占用的方法，包括使用 `netstat` 命令、PowerShell、TCPView 工具以及资源监视器。  


## 1. 使用 `netstat` 命令  

### 1.1 操作步骤  

1. **打开命令提示符（CMD）或 PowerShell**  
   - 按 `Win + R` 键，输入 `cmd` 或 `powershell`，然后按回车。  

2. **输入以下命令并回车**  
   ```bash
   netstat -ano | findstr :53317
   ```
   - `netstat -ano`：列出所有活动的网络连接和监听端口。  
   - `findstr :53317`：过滤出包含 `:53317` 的行。  

3. **查看输出结果**  
   - 最后一列是 `PID`（进程 ID），记下这个 PID。  

4. **查找对应的进程**  
   - **打开任务管理器**（`Ctrl + Shift + Esc`）。  
   - 切换到“详细信息”选项卡。  
   - 找到对应的 PID，查看是哪个进程占用了该端口。  

---

## 2. 使用 PowerShell `Get-Process` 命令  

### 2.1 操作步骤  

1. **打开 PowerShell**  
2. **输入以下命令并回车**  
   ```powershell
   Get-Process -Id (Get-NetTCPConnection -LocalPort 53317).OwningProcess
   ```
   - 该命令直接显示占用 53317 端口的进程信息。  

---

## 3. 使用第三方工具（TCPView）  

### 3.1 下载及运行  

1. **下载并运行 [Sysinternals TCPView](https://learn.microsoft.com/en-us/sysinternals/downloads/tcpview)**。  
2. **查找端口信息**  
   - 在 TCPView 界面中，查找 `Local Port` 列，找到 `53317`。  
   - 查看对应的 `Process` 列，了解是哪个进程占用了该端口。  

---

## 4. 使用 `资源监视器`  

### 4.1 操作步骤  

1. **打开任务管理器**（`Ctrl + Shift + Esc`）。  
2. **切换到“性能”选项卡，点击底部的“打开资源监视器”**。  
3. **在“资源监视器”中，切换到“网络”选项卡**。  
4. **查找端口信息**  
   - 在“TCP 连接”部分，查找 `本地端口` 为 `53317` 的行。  
   - 查看对应的 `PID` 和进程名称。
