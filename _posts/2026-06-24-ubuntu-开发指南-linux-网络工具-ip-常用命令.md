## `ip` 命令常用操作 (iproute2)

`ip` 命令的操作对象非常广泛，常用的子命令包括 `link`（物理或虚拟链路）、`addr`（IP 地址）、`route`（路由表）和 `neigh`（ARP/邻居表）。

### 1. 链路状态管理 (`ip link`)

主要用于控制网卡的物理/数据链路层状态（如开启/关闭、修改 MAC 地址、调整 MTU）。

| 需求                 | 命令                      | 说明                                    |
| -------------------- | ------------------------- | --------------------------------------- |
| **查看所有网卡状态** | `ip link show` 或 `ip l`  | 查看所有接口的 MAC、MTU、UP/DOWN 状态。 |
| **查看特定网卡状态** | `ip link show eth0`       | 仅查看 `eth0` 的状态。                  |
| **启用/禁用网卡**    | `ip link set eth0 up`<br> |

<br>`ip link set eth0 down` | 等同于旧的 `ifconfig eth0 up/down`。在硬件调试时，常用于重置网卡状态。 |
| **修改 MAC 地址** | `ip link set eth0 address 00:11:22:33:44:55` | 修改前通常需要先 `down` 掉该网卡。 |
| **修改 MTU** | `ip link set eth0 mtu 1492` | 调整最大传输单元。 |

### 2. IP 地址管理 (`ip addr`)

用于配置和查看网络层的 IPv4/IPv6 地址。

| 需求                 | 命令                                    | 说明                                                   |
| -------------------- | --------------------------------------- | ------------------------------------------------------ |
| **查看所有 IP 地址** | `ip addr show` 或 `ip a`                | 列出所有接口的 IP 信息。                               |
| **查看特定网卡 IP**  | `ip addr show eth0`                     | 仅查看 `eth0` 的 IP。                                  |
| **动态添加 IP 地址** | `ip addr add 192.168.1.100/24 dev eth0` | 为网卡绑定一个静态 IP（可以绑定多个，即单网卡多 IP）。 |
| **删除 IP 地址**     | `ip addr del 192.168.1.100/24 dev eth0` | 移除已绑定的 IP。                                      |
| **清空网卡所有 IP**  | `ip addr flush dev eth0`                | 快速清除该网卡上的所有 IP 配置。                       |

### 3. 路由与网关管理 (`ip route`)

用于排查网络不通、多网卡路由冲突（例如同时连接内网 eth0 和外网 wlan0 时）。

| 需求               | 命令                                                 | 说明                                 |
| ------------------ | ---------------------------------------------------- | ------------------------------------ |
| **查看当前路由表** | `ip route show` 或 `ip r`                            | 查看当前的路由规则和默认网关。       |
| **添加默认网关**   | `ip route add default via 192.168.1.1`               | 所有未知流量都将发往此网关。         |
| **添加静态路由**   | `ip route add 10.0.0.0/8 via 192.168.1.254 dev eth0` | 访问特定网段时强制走特定网卡和网关。 |
| **删除路由**       | `ip route del 10.0.0.0/8`                            | 删除特定路由规则。                   |

### 4. ARP 与邻居缓存 (`ip neigh`)

排查 IP 冲突或局域网设备通信问题。

| 需求              | 命令                      | 说明                                                                       |
| ----------------- | ------------------------- | -------------------------------------------------------------------------- |
| **查看 ARP 缓存** | `ip neigh show` 或 `ip n` | 查看局域网内已知设备的 IP 与 MAC 对应关系及状态 (REACHABLE/STALE/FAILED)。 |
| **清除 ARP 缓存** | `ip neigh flush all`      | 在局域网拓扑变动或怀疑缓存污染时强制清空。                                 |
