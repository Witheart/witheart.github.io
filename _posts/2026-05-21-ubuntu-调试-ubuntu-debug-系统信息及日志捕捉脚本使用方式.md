本工具用于在设备出现异常、卡顿、死机或功能失效时，一键自动收集设备底层的运行状态与系统日志，并自动打包。请按照以下简单的步骤进行操作：

## 第一步：将脚本拷贝到设备中

使用 U 盘或网络工具，将调试脚本 `rk_ubuntu_debug.sh` 拷贝到设备的任意目录下（例如 `/tmp` 或主目录）。

## 第二步：打开终端并运行

在设备上打开终端（Terminal），或者通过 SSH 远程登录，切换到脚本所在目录，执行以下两条命令：

```bash
# 1. 赋予脚本执行权限
chmod +x rk_ubuntu_debug.sh

# 2. 使用管理员权限运行脚本（必须使用 sudo，否则部分底层硬件信息无法读取）
sudo ./rk_ubuntu_debug.sh

```

> **可选参数：**
>
> - 脚本默认抓取最近 10 次的开机日志。如果想抓 20 次，可运行：`sudo ./rk_ubuntu_debug.sh -j 20`
> - 如果设备没联网且提示缺少依赖工具，可以强制忽略报错强行运行：`sudo ./rk_ubuntu_debug.sh -i`

## 第三步：等待完成，获取文件

脚本运行大约需要 **15~30秒**，期间屏幕会滚动显示进度。当看到如下信息时，说明采集已经圆满成功：

```text
=========================================================
[✓] 调试日志捕捉与归档圆满成功！
---------------------------------------------------------
[📍 Log 本地位置]: /tmp/log-RK3568X20260521-20260521_223457.zip
---------------------------------------------------------
[📢 重要提示]: 请将上述 zip 压缩包通过网络或 U 盘
               回传给研发人员进行问题定位与故障深度分析。
=========================================================

```

---

## 故障回传与善后工作

1. **提取文件：** 前往系统的 `/tmp` 目录下，找到上面提示框中对应的 `.zip` 压缩包。
2. **回传研发：** 请将此压缩包发送给对接的**研发人员**。
