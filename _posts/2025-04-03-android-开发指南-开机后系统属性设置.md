概要：本文介绍了如何在 Android 系统开机后设置持久化属性，列举了常用命令及属性文件的保存位置，帮助开发者理解系统属性配置的具体实现方式。  


## 1. 查看系统现有属性  

使用以下命令可以查看当前系统所有属性：  

```bash
getprop
```

---

## 2. 开机后设置持久化属性  

可以通过以下命令设置持久化属性，例如设置UI绘制分辨率：  

```bash
setprop persist.vendor.framebuffer.main 800x1280
```

### 2.1 属性保存位置  

设置后，属性会保存在以下文件中：  

- `/data/property/persistent_properties`

---

## 3. 各类属性文件说明  

- `/data/property/persistent_properties`：保存持久化属性。
- `/system/build.prop`：可查看系统的编译日期。
- `/vendor/build.prop`：保存 SDK 配置的自定义属性。
- `/default.prop` 与 `/system/etc/prop.default`：这两个文件内容相同。
