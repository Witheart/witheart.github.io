对应系统设置下-显示-永久隐藏状态栏选项

## 补丁
注意，状态栏有两种设置，一种是永久隐藏状态栏（对应Settings.System.ALWAYS_HIDE_BAR），另一种是自动隐藏状态栏（对应Settings.System.AUTO_HIDE_BAR）

本文前提：应用了以下补丁
a5edd51: 支持屏幕旋转，支持隐藏任务栏

## 操作
adb下：
```bash
su
# 关闭隐藏
settings put system always_hide_bar 0

# 开启隐藏
settings put system always_hide_bar 1

# 可使用该命令查看更改是否成功
grep always_hide_bar /data/system/users/0/settings_system.xml
# 或者
settings get system always_hide_bar

# 运行后重启
reboot
```

## 溯源
查看a5edd51
发现如下代码
```java
boolean hide_systembar = Settings.System.getInt(mContext.getContentResolver(),Settings.System.ALWAYS_HIDE_BAR,0) != 0;
```
说明状态栏的状态依赖于Settings.System.ALWAYS_HIDE_BAR，提供了以下信息：
- 系统级设置​​ → Settings.System
​​- 整型值​​ → .getInt()
​​- 键名全称​​ → ALWAYS_HIDE_BAR
故使用settings put system always_hide_bar 0进行设置
注意：此处不能使用setporp，详见《Android 系统属性 与 系统设置 的区别》
