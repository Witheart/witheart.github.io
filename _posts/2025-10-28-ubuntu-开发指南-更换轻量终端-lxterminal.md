## 使用 apt 安装

```bash
# 1. 更新软件包列表（可选，但推荐）
sudo apt update

# 2. 安装 lxterminal
sudo apt install lxterminal

# 3. 安装完成后，可以直接启动
lxterminal
```

## 安装后的使用

**启动方式：**
- 在终端中输入 `lxterminal`
- 在应用程序菜单中搜索 "LXTerminal"
- 可以设置为默认终端
