## 接口概述

![alt text](/assets/images/基础知识/m-2-msata-接口区别/PixPin_2025-07-31_11-26-39.png)

M.2 和 mSATA 是两种不同的存储设备接口，其中 M.2 接口尺寸更小，应用更广泛。

## 主要区别

### 1. M.2 接口

- **主要用途**：主要用于 SSD 固态硬盘
- **总线类型**：
  - SATA 总线版本
  - PCIe 总线版本
- **支持协议**：
  - AHCI 协议
  - NVMe 协议
- **多功能性**：M.2 插槽也可用于其他设备（如图中的 AI 加速卡）

| 接口类型  | 接口细节                         | 总线(通道) | 协议      | 速度 |
| --------- | -------------------------------- | ---------- | --------- | ---- |
| M.2(ngff) | Socket 2 (B key)<br>(6 个金手指) | SATA       | AHCI 协议 | 慢   |
|           |                                  | PCIe x2    | AHCI 协议 |      |
|           | Socket 3 (M key)<br>(5 个金手指) | PCIe x4    | AHCI 协议 |      |
|           |                                  | PCIe x4    | NVMe 协议 | 快   |

注：M.2 接口的不同 Socket 类型（B key 和 M key）支持不同的总线类型和协议组合，从而影响传输速度。

### 2. mSATA 接口

- **插槽类型**：基于 mini PCIe（MPE）插槽
- **主要用途**：支持 SATA 总线的硬盘
- **扩展功能**：mini PCIe 插槽还可用于：

  - 4G 网卡
  - WiFi 卡等设备
