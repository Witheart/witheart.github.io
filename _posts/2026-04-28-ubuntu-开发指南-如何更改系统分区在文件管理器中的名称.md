1.  **确认分区设备路径**
    打开终端，使用 `lsblk -f` 命令查看所有磁盘和分区。找到分区，记下它的设备名（例如 `/dev/sdb1`）。

2.  **设置文件系统标签**
    使用 `e2label` 命令（专用于ext2/3/4文件系统）来修改标签。命令格式为：
    ```bash
    sudo e2label /dev/sdXN 新标签名
    ```

    - 请将 `/dev/sdXN` 替换为你实际的分区设备路径。
    - 将 `新标签名` 替换为你想要的名称（例如 `MyData`）。
    - 执行命令需要输入管理员密码。

**例如：**
假设你的分区是 `/dev/sdb1`，想改名为 `Backup`，则命令为：

```bash
sudo e2label /dev/sdb1 Backup
```

3.  **生效查看**
    设置完成后，在pcmanfm中刷新或重新挂载该分区，即可看到新名称。

**请注意：**

- 标签名最好避免使用特殊字符和空格。
- 此操作不会影响分区内的数据。

## 原理
e2label 命令（专用于ext2/3/4文件系统）来修改标签，直接写入在该分区自己的文件系统头部（元数据）里。
