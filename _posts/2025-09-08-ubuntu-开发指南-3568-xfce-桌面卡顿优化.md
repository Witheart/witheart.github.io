本文提供了多种提升 XFCE 桌面流畅度的设置建议，用户可根据实际使用体验，自由选择搭配使用，无需全部应用。


## 1 调整外观

`左上角开始菜单 -> 设置 -> 外观`

- 调整样式为`Greybird`
  ![样式调整](/assets/images/ubuntu-开发指南/3568-xfce-桌面卡顿优化/PixPin_2025-09-08_10-46-55.png)
- 调整图标为`elementart Xfce`
  ![图标调整](/assets/images/ubuntu-开发指南/3568-xfce-桌面卡顿优化/PixPin_2025-09-08_10-49-27.png)

## 2 调整显示合成

`左上角开始菜单 -> 设置 -> 窗口管理器微调`

- 取消勾选`启用显示合成`可以大幅度减少卡顿，不跟手的问题，代价是无法显示窗口的透明效果，窗口可能出现黑边
- 如果不取消勾选`启用显示合成`，可以尝试开关其中的选项，原则上，关闭所有阴影选项，将不透明度都改为不透明
  ![合成器设置](/assets/images/ubuntu-开发指南/3568-xfce-桌面卡顿优化/image.png)

## 3 关闭其他透明效果

### 3.1 关闭面板透明

`右键面板 -> 菜单中选择面板 -> 面板首选项`

- 样式改为纯色，颜色替换为纯色的背景（默认是透明的网格）
  ![面板样式设置](/assets/images/ubuntu-开发指南/3568-xfce-桌面卡顿优化/PixPin_2025-09-08_11-00-44.png)

### 3.2 关闭开始菜单透明

`右键开始菜单图标 -> 属性`
- 调整背景不透明度为100%
![开始菜单背景设置](/assets/images/ubuntu-开发指南/3568-xfce-桌面卡顿优化/PixPin_2025-09-08_11-06-32.png)

### 3.3 关闭终端透明
`打开终端 -> 右键终端输入命令处 -> 首选项`
- 背景设置为`无(使用纯色)`
![终端背景设置](/assets/images/ubuntu-开发指南/3568-xfce-桌面卡顿优化/PixPin_2025-09-08_11-09-35.png)

## 4 卸载plank
plank是桌面下方的快速启动任务栏，动画较多，可以尝试卸载。
```bash
sudo apt remove plank -y
```

## 5 更换较重的应用
文件管理器Thunar -> PCManFM
终端xfce4-terminal -> lxterminal
