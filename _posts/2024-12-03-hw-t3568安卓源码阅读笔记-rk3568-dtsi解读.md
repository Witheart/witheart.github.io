# `display_subsystem` 节点

- **compatible**：定义了这个节点代表Rockchip的显示子系统。
- **memory-region** 和 **memory-region-names**：指定了用于显示的内存区域，包括DRM（Direct Rendering Manager）相关的区域。
- **ports**：指向视频输出端口节点。
- **devfreq**：指向动态频率调整控制器节点，用于调整显示子系统的频率。

## `route` 子节点

- 这个节点定义了不同的显示输出路由，每个子节点代表一种输出方式（如DSI, HDMI, EDP等），包括：
  - **status**：通常设为"disabled"，表示这些输出方式在启动时默认不启用。
  - **logo,uboot** 和 **logo,kernel**：指定在启动时显示的图标。
  - **logo,mode** 和 **charge_logo,mode**：定义了启动图标的显示模式。
  - **connect**：指定了该输出方式连接的视频输出端口。

## 作用
1. 修改 logo 显示
2. 修改 vp 与 dsi 的连接关系

# 修改接口对应的控制器（如I2C、uart）
## I2C
Rockchip RK3568 TRM Part1 V1.1-20210301.pdf
P733

修改：pinctrl-0 = <&i2c3m1_xfer>;
```
i2c3: i2c@fe5c0000 {
		compatible = "rockchip,rk3399-i2c";
		reg = <0x0 0xfe5c0000 0x0 0x1000>;
		clocks = <&cru CLK_I2C3>, <&cru PCLK_I2C3>;
		clock-names = "i2c", "pclk";
		interrupts = <GIC_SPI 49 IRQ_TYPE_LEVEL_HIGH>;
		pinctrl-names = "default";
		//pinctrl-0 = <&i2c3m0_xfer>;
		pinctrl-0 = <&i2c3m1_xfer>;
		#address-cells = <1>;
		#size-cells = <0>;
		status = "disabled";
	};
```

## UART

```
uart3: serial@fe670000 {
		compatible = "rockchip,rk3568-uart", "snps,dw-apb-uart";
		reg = <0x0 0xfe670000 0x0 0x100>;
		interrupts = <GIC_SPI 119 IRQ_TYPE_LEVEL_HIGH>;
		clocks = <&cru SCLK_UART3>, <&cru PCLK_UART3>;
		clock-names = "baudclk", "apb_pclk";
		reg-shift = <2>;
		reg-io-width = <4>;
		dmas = <&dmac0 6>, <&dmac0 7>;
		pinctrl-names = "default";
		pinctrl-0 = <&uart3m1_xfer>;
		status = "disabled";
	};
```
