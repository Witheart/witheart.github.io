## 终端使用方式
接入键盘，快捷键Ctrl+Alt+T
如果不能唤起终端，鼠标点击桌面空白处后再次尝试
终端唤起后，如果是普通用户模式（显示user@user），输入su切换为root用户，密码为123456
密码输入过程中没有显示，为正常现象，输入完毕后按回车确认即可
切换成功显示root@user
![alt text](/assets/images/测试sop/hw-t3568i-ubuntu-接口测试-2/image-5.png)

## 测试工具位置与使用
将测试用工具放入fat 格式U盘的英文路径文件夹中，插入待测板
### 方式一
桌面点击Computer图标
![alt text](/assets/images/测试sop/hw-t3568i-ubuntu-接口测试-2/image-6.png)

在弹出窗口的左侧一栏中，点击进入U盘目录
![alt text](/assets/images/测试sop/hw-t3568i-ubuntu-接口测试-2/image-7.png)

进入测试工具所在文件夹
![alt text](/assets/images/测试sop/hw-t3568i-ubuntu-接口测试-2/image-8.png)

点击地址栏，右键复制地址
![alt text](/assets/images/测试sop/hw-t3568i-ubuntu-接口测试-2/image-9.png)

打开终端，在终端中输入cd和空格，然后将地址复制进去，点击回车进入到测试工具所在文件夹
![alt text](/assets/images/测试sop/hw-t3568i-ubuntu-接口测试-2/image-10.png)

### 方式二
打开终端，在终端中输入
cd /media/user/
然后按Tab补全，找到U盘目录，进入待测工具文件夹

## Audio

## GPIO
使用GPIO测试线，对接GPIO，使用GPIO脚本进行测试。
治具定义：
短接pin1-2、pin3-4、pin6-7、pin8-9
![alt text](/assets/images/测试sop/hw-t3568i-ubuntu-接口测试-2/image-2.png)

打开终端，进入脚本所在目录
命令：
```bash
sudo chmod +x T3568_gpio_test.sh

sudo ./T3568_gpio_test.sh
```

测试成功输出示例：
![alt text](/assets/images/测试sop/hw-t3568i-ubuntu-接口测试-2/image-3.png)

## COM
接入COM loop测试线，使用脚本进行回环测试。
COM1治具定义：
短接TXRX
![alt text](/assets/images/测试sop/hw-t3568i-ubuntu-接口测试-2/image-4.png)
COM2-COM6治具定义：
短接pin2-3
![alt text](/assets/images/测试sop/hw-t3568i-ubuntu-接口测试-2/image-1.png)

打开终端，进入脚本所在目录
命令：
```bash
sudo python3 T3568_uart_test.py
```

测试成功输出示例：
![alt text](/assets/images/测试sop/hw-t3568i-ubuntu-接口测试-2/image.png)
