构建适用于 RK3568（基于 ARM64 架构）的 Ubuntu 根文件系统，最主流且高效的方法是使用官方的 **Ubuntu Base** 镜像，配合主机（通常是 x86 架构的 PC）上的 **qemu-user-static** 工具，通过 `chroot` 的方式进行模拟构建。

## 准备工作

在 x86 Ubuntu 主机上，安装必要的交叉编译和模拟运行工具：

```bash
sudo apt update
sudo apt install qemu-user-static binfmt-support

```

---

## 第一步：下载并解压 Ubuntu Base

下载适用于 ARM64 的 Ubuntu Base 压缩包（也可以选择 22.04 Jammy）。

```bash
# 创建工作目录
mkdir rk3568_ubuntu
cd rk3568_ubuntu

# 下载 ubuntu-base arm64 镜像
wget http://cdimage.ubuntu.com/ubuntu-base/releases/20.04/release/ubuntu-base-20.04.5-base-arm64.tar.gz

# 创建根文件系统目录并解压
mkdir ubuntu-rootfs
sudo tar -xpf ubuntu-base-20.04.5-base-arm64.tar.gz -C ubuntu-rootfs/

```

---

## 第二步：配置 QEMU 和网络

为了能让 x86 主机运行 ARM64 的系统并连接网络下载软件包，需要拷贝 QEMU 模拟器和主机的 DNS 配置到根文件系统中。

```bash
# 拷贝 qemu-aarch64-static
sudo cp /usr/bin/qemu-aarch64-static ubuntu-rootfs/usr/bin/

# 拷贝 DNS 配置，以便在 chroot 环境中可以联网
sudo cp -b /etc/resolv.conf ubuntu-rootfs/etc/resolv.conf

```

qemu-user-static 让 x86_64 电脑可直接执行为 ARM64（或其他架构）编译的用户态二进制程序。

---

## 第三步：挂载节点并进入 Chroot 环境

编写一个挂载和卸载的脚本（或者直接手动执行），这里我们手动执行挂载并进入系统：

```bash
# 挂载宿主机的设备节点和系统目录
sudo mount -t proc /proc ubuntu-rootfs/proc
sudo mount -t sysfs /sys ubuntu-rootfs/sys
sudo mount -o bind /dev ubuntu-rootfs/dev
sudo mount -o bind /dev/pts ubuntu-rootfs/dev/pts

# 切换进入 ubuntu-rootfs
sudo chroot ubuntu-rootfs

```

此时，已经“进入”了即将运行在 RK3568 上的 Ubuntu 系统中。

---

## 第四步：在 Chroot 环境中配置系统（重点）

在 `chroot` 环境下，执行以下操作来完善的根文件系统。

**1. 更新软件源并安装基础软件**
修改软件源（可选，国内建议换成清华或中科大源的 ARM64 专属源 `ubuntu-ports`）：

```bash
# 1. 备份原有的源文件
sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak

# 2. 将官方的 ports.ubuntu.com 替换为清华源
sudo sed -i 's/ports.ubuntu.com/mirrors.tuna.tsinghua.edu.cn/g' /etc/apt/sources.list
```

然后更新并安装必要工具：

```bash
apt update
apt upgrade -y
# 安装基础工具、网络管理、SSH、文本编辑器等
apt install -y sudo vim net-tools ethtool ifupdown network-manager ssh iputils-ping rsyslog bash-completion

```

安装XFCE4桌面相关：

```bash
# 安装 XFCE4 核心组件、Xorg 显示服务器和 LightDM 登录管理器
apt install -y xfce4 xfce4-terminal xorg lightdm

# 安装网络管理器的图形前端（方便在桌面连 WiFi/网线）
apt install -y network-manager-gnome

# 设置系统默认启动到图形界面
systemctl set-default graphical.target
```

**2. 设置主机名和时区**

```bash
echo "rk3568" > /etc/hostname
echo "127.0.0.1 localhost rk3568" >> /etc/hosts

# 设置时区为上海
ln -sf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
dpkg-reconfigure -f noninteractive tzdata

```

**3. 添加用户和设置密码**

```bash
# 设置 root 密码
passwd root

# 创建新用户（例如 user）并赋予 sudo 权限
useradd -G sudo -m -s /bin/bash user
passwd user

```

**4. 适配 RK3568 的串口输出**
RK3568 默认使用的调试串口通常是 `ttyFIQ0`（波特率通常为 1500000）。如果不配置，系统启动后串口可能没有登录提示符。

```bash
ln -s /lib/systemd/system/serial-getty@.service /etc/systemd/system/getty.target.wants/serial-getty@ttyFIQ0.service

```

**5. 将“极度精简版”的 Ubuntu 恢复成“标准完整版”的 Ubuntu 基础系统**
```bash
sudo unminimize
```

**6. 清理并退出 chroot**

```bash
# 清理缓存以减小镜像体积
apt clean
rm -rf /var/lib/apt/lists/*

# 退出 chroot
exit

```

## 第五步：卸载节点并打包镜像

退出 `chroot` 后，回到宿主机的终端，先卸载刚刚挂载的目录：

```bash
sudo umount ubuntu-rootfs/dev/pts
sudo umount ubuntu-rootfs/dev
sudo umount ubuntu-rootfs/sys
sudo umount ubuntu-rootfs/proc

```

接下来，将目录打包成可以通过 Rockchip 烧录工具（如 RKDevTool）烧录的 `.img` 文件。

**使用 `make_ext4fs` 或 `dd` 生成镜像：**

这里提供使用 `dd` 和 `mkfs.ext4` 的标准做法：

```bash
# 计算 rootfs 目录的大小，这里预分配 4G 大小（根据安装的软件多少调整）
dd if=/dev/zero of=rootfs.img bs=1M count=4096

# 将文件格式化为 ext4
sudo mkfs.ext4 rootfs.img

# 挂载镜像并将文件拷贝进去
mkdir mnt
sudo mount rootfs.img mnt/
sudo cp -rfp ubuntu-rootfs/* mnt/

# 卸载镜像
sudo umount mnt/
sudo e2fsck -p -f rootfs.img
sudo resize2fs -M rootfs.img  # 压缩镜像到最小尺寸

```

至此，`rootfs.img` 已经生成完毕。可以将其与 RK3568 的 U-Boot、Kernel（boot.img）、dtb 文件一起打包烧录到板子上。
