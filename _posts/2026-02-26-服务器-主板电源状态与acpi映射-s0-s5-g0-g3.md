## 1 ACPI 全局状态（G-States）（Global）

| 全局状态 | 名称           | 是否上电   | 说明                       |
| -------- | -------------- | ---------- | -------------------------- |
| G0       | Working        | 是         | 系统正常运行（对应 S0）    |
| G1       | Sleeping       | 部分       | 睡眠状态集合（包含 S1–S4） |
| G2       | Soft Off       | 仅待机电源 | 软关机（对应 S5）          |
| G3       | Mechanical Off | 否         | 机械断电，完全无电         |

## 4 Deep Sx 状态

参考《606161 Emmitsburg_EDS Rev 1-5》P2144

Deep Sx 是在基于 Intel Platform Controller Hub（PCH）的系统中提供的一种**可选的超低功耗状态**，属于 Sx 状态的“深度版本”。

它的核心特点：

- 属于 S3 / S4 / S5 的进一步降功耗版本
- 几乎所有电源轨关闭
- 仅保留极少数用于“唤醒”的逻辑
- 是否保存系统上下文取决于**进入时的状态**

### 4.1 Deep Sx的行为逻辑

Deep Sx 不是独立电源状态，而是“叠加”在 S3/S4/S5 上的深度版本：

| 进入来源           | 恢复后回到  |
| ------------------ | ----------- |
| 从 S3 进入 Deep Sx | 恢复后回 S3 |
| 从 S4 进入 Deep Sx | 恢复后回 S4 |
| 从 S5 进入 Deep Sx | 恢复后回 S5 |

- Deep Sx **不改变原本的系统语义**
- 只是进一步降低功耗
- PCH 会记住“你是从哪个 Sx 进来的”

### General Power States for Systems Using the PCH

| State/Substate | Legacy Name       | Description                                                                     |
| -------------- | ----------------- | ------------------------------------------------------------------------------- |
| G0/S0/C0       | Full On           | 处理器运行状态。设备可单独进入低功耗状态。                                      |
| G0/S0/Cx       | Processor C-State | 处理器内部功耗管理状态，由CPU自行管理，不直接传递给PCH，仅发送相关消息。        |
| G1/S3          | Suspend-To-RAM    | 系统上下文保存在DRAM中。非关键电路断电，内存保持刷新，仅RTC继续运行。           |
| G1/S4          | Suspend-To-Disk   | 系统上下文保存到磁盘。系统几乎完全断电，仅保留恢复逻辑。                        |
| G2/S5          | Soft Off          | 不保存系统上下文。几乎完全断电，唤醒需要完整启动。                              |
| Deep Sx        | Deep Sleep State  | 可选超低功耗状态。根据进入来源（S3/S4/S5）决定恢复路径。仅保留最小唤醒逻辑。    |
| G3             | Mechanical Off    | 机械断电状态。仅RTC供电。不可唤醒。恢复行为取决于断电前状态及 AFTERG3_EN 配置。 |

## 5 完整电源状态结构关系图

```
G0  (Working)
 └── S0
      └── C0/Cx

G1  (Sleeping)
 ├── S3 (STR)
 └── S4 (STD)

G2
 └── S5 (Soft Off)

Deep Sx  (Overlay on S3/S4/S5)

G3  (Mechanical Off)
```
