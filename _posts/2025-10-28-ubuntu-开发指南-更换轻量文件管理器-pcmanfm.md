### 安装方式

使用 `apt` 包管理器。

```bash
sudo apt update
sudo apt install pcmanfm
```

### 启动方式

两种方式

1.  **在终端中直接输入：**
    ```bash
    pcmanfm
    ```

2.  **在应用程序菜单中查找：** 通常在菜单的“系统工具”或“工具”类别下，名字通常是“PCManFM 文件管理器”。
