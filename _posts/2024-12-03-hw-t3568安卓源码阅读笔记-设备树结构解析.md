# **设备树层次结构**

**适用版型**：HW-T3568

## **设备树文件层次结构**

```plaintext
NK_RK3568.dts            # 顶层设备树文件
  └── NK_RK3568.dtsi     # 定制板型设备树配置
      ├── rk3568.dtsi    # RK3568 芯片级设备树配置
      │   └── rk3568-dram-default-timing.dtsi  # DRAM 默认时序配置
      |   └── rk3568-pinctrl.dtsi
      └── rk3568-evb.dtsi # 开发板相关配置
  └── rk3568-android.dtsi # Android 系统相关配置
```

---

## **文件说明**

1. **NK_RK3568.dts**

   - 顶层设备树文件，包含 HW-T3568 板型的整体配置入口。
   - 引用其他子设备树文件，如 `NK_RK3568.dtsi`。

2. **NK_RK3568.dtsi**

   - 定制硬件相关配置文件，定义 HW-T3568 板型的特定硬件资源和引脚设置。
   - 包含对芯片级配置文件（`rk3568.dtsi`）和开发板配置文件（`rk3568-evb.dtsi`）的引用。
   - 添加了定制化的外设配置，例如特定的 GPIO、音频设备、电源管理器、MIPI 屏幕、摄像头等。
   - 包括为特定硬件平台定制的模块启用状态和引脚复用配置。

3. **rk3568.dtsi**

   - RK3568 芯片级通用配置，定义 SoC 的核心资源（如 GPIO、I2C、SPI 等）。
   - 还引用了 DRAM 时序配置文件（`rk3568-dram-default-timing.dtsi`）。

4. **rk3568-dram-default-timing.dtsi**

   - DRAM 默认时序配置文件，定义芯片初始内存控制逻辑和时序参数。

5. **rk3568-evb.dtsi**

   - 开发板（Evaluation Board, EVB）相关配置文件，定义与开发板匹配的硬件资源。
   - 启用了评估板上实际使用的硬件模块（如 UART、I2C、SPI、显示接口等）。
   - 定义了评估板专属的外部设备（如 LCD 屏幕、背光、LED 指示灯等）。
   - 包括评估板上电源管理的具体配置。

6. **rk3568-android.dtsi**
   - Android 系统相关配置文件，定义适配 Android 平台的特定硬件设置。
