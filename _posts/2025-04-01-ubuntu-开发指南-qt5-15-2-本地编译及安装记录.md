## 2. 编译步骤  

### 2.1 安装依赖包  

首先更新系统软件包列表，并安装编译 Qt 所需的依赖库：  

```bash
apt update
apt install build-essential libgl1-mesa-dev libxkbcommon-dev libxkbcommon-x11-dev \
libxcb-xinerama0-dev libxcb-xinerama0 libxcb-icccm4-dev libxcb-image0-dev \
libxcb-keysyms1-dev libxcb-render-util0-dev libxcb-shape0-dev libxcb-sync-dev \
libxcb-xfixes0-dev libxcb-xkb-dev libxcb1-dev libxcb1 libxrender-dev libx11-dev \
libx11-xcb-dev libxi-dev libxext-dev libfontconfig1-dev libfreetype6-dev \
libpng-dev libjpeg-dev libssl-dev libdbus-1-dev libicu-dev libpulse-dev \
libasound2-dev libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev
```

继续安装 Wayland 和 Python 支持：  

```bash
apt install libwayland-dev
apt install python
```

./plugins/platforms/libqxcb.so 库可能即使编译选项中显示的是yes，也可能编译不出来，为了使尽可能编译出来，先安装官网提到这些包
https://doc.qt.io/qt-5/linux-requirements.html

```bash
sudo apt install libfontconfig1-dev libfreetype6-dev libx11-dev libx11-xcb-dev libxext-dev libxfixes-dev libxi-dev libxrender-dev libxcb1-dev libxcb-glx0-dev libxcb-keysyms1-dev libxcb-image0-dev libxcb-shm0-dev libxcb-icccm4-dev libxcb-sync-dev libxcb-xfixes0-dev libxcb-shape0-dev libxcb-randr0-dev libxcb-render-util0-dev libxcb-xinerama-dev libxkbcommon-dev libxkbcommon-x11-dev
```

下面这几个包在Ubuntu20.04中可能安装失败，原因是改名了
```bash
sudo apt install libglib2-dev libsrtp0-dev libxcb-xinerama-dev
```
更新为
```bash
sudo apt install libglib2.0-dev libsrtp2-dev libxcb-xinerama0-dev
```

### 2.2 进入源码目录并配置编译参数  

```bash
./configure -prefix /opt/Qt5.15.2 -opensource -confirm-license -release   -nomake examples -nomake tests -no-openssl -no-icu -skip qtlocation -xcb -xcb-xlib -bundled-xcb-xinput
```

参数说明：  

- **-prefix**：指定安装路径为 `/opt/Qt5.15.2`  
- **-opensource**：使用开源许可证  
- **-confirm-license**：自动确认许可证  
- **-release**：编译 release 版本  
- **-nomake examples/tests**：跳过示例和测试编译  
- **-no-openssl / -no-icu**：不启用 OpenSSL 和 ICU 支持  
- **-skip qtlocation**：跳过 qtlocation 模块  
- ​**-xcb**：启用 ​XCB（X Protocol C Binding）​ 作为 Linux/X11 的图形后端（默认可能已启用）。
- ​**-xcb-xlib**：启用 ​XCB 与 Xlib 的兼容层，确保与旧版 X11 应用的兼容性。
- ​**-bundled-xcb-xinput**：使用 Qt 自带的 ​xcb-xinput 库​（而非系统安装版本），避免系统库版本不兼容问题。

- 如果报错
```sh
Feature 'xcb' was enabled, but the pre-condition 'features.thread && libs.xcb && tests.xcb_syslibs && features.xkbcommon-x11' failed.
```

- 尝试安装
```bash
sudo apt-get install '^libxcb.*-dev' libx11-xcb-dev libglu1-mesa-dev libxrender-dev libxi-dev libxkbcommon-dev libxkbcommon-x11-dev
```

- 如果还是报错，执行
```bash
./configure -recheck-all
```

- 然后重新执行
```bash
./configure -prefix /opt/Qt5.15.2 -opensource -confirm-license -release   -nomake examples -nomake tests -no-openssl -no-icu -skip qtlocation -xcb -xcb-xlib -bundled-xcb-xinput
```

---

### 2.3 编译与安装  

使用多线程编译，加快构建速度（根据 CPU 核心数自动并行）：  

```bash
make -j$(nproc)
make install
```
