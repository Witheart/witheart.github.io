## 1 需求

改系统分区为：
EMMC:根分区20G，Swap8G，home10G，var20G
mSATA: data分区
![alt text](/assets/images/ubuntu-开发指南/3588-ubuntu-重新分配分区指南/PixPin_2026-04-27_11-12-04.png)

## 2 思路

之前是整个根文件系统，使用打包脚本打包，编译时，根据参数表，将根分区打包到完整的镜像中。

现在需要修改打包脚本，将要分出来的各个分区分别打包，然后修改参数表，将这些img一起打包到完整的镜像中。

## 6 修改fstab

```bash
$ cat /etc/fstab
PARTLABEL=home   /home   ext4   defaults   0 2
PARTLABEL=var    /var    ext4   defaults   0 2
PARTLABEL=swap   none    swap   sw,nofail,x-systemd.device-timeout=5s         0 0
LABEL=data       /data   ext4   defaults,nofail,x-systemd.device-timeout=5s   0 2

```
