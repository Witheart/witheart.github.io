概要：本文介绍了 EC200M-CN 模块的接入方式，包括端口识别、网卡模式配置（ECM/RNDIS）、拨号脚本、SIM 卡状态查看等操作，适用于快速部署 4G 网络连接。


## 1. 模块基本信息  

- **VID**：`0x2c7c`  
- **PID**：`0x6002`  

---

## 2. 端口说明与识别  

### 2.1 端口生成  

模块会生成 3 个 `/dev/ttyUSB` 节点：  

- `/dev/ttyUSB0`  
- `/dev/ttyUSB1` — 用于发送 AT 指令  
- `/dev/ttyUSB2` — 同样可用于发送 AT 指令  

### 2.2 识别模块是否加载成功  

```bash
ls /dev/ttyUSB*

# 示例输出
/dev/ttyUSB0  /dev/ttyUSB1  /dev/ttyUSB2
```

或使用 `lsusb` 命令查看是否识别出模块：

```bash
lsusb

# 应包含以下信息
ID 2c7c:6002
```

---

## 3. 配置网卡模式  

### 3.1 可选模式  

- `AT+QCFG="usbnet",1`：配置为 ECM 模式  
- `AT+QCFG="usbnet",3`：配置为 RNDIS 模式  

### 3.2 查询当前网卡模式  

```bash
# 开启后台监听响应
cat /dev/ttyUSB2 &

# 查询当前模式
echo -e "AT+QCFG=\"usbnet\"\r\n" > /dev/ttyUSB2

# 返回示例：
+QCFG: "usbnet",3  # 表示当前为 RNDIS 模式
```

### 3.3 设置为 ECM 模式（配置一次即可，模块会保存）  

```bash
# 开启后台监听
cat /dev/ttyUSB2 &

# 设置为 ECM 模式
echo -e "AT+QCFG=\"usbnet\",1\r\n" > /dev/ttyUSB2

# 重启模块以使配置生效
echo -e "AT+CFUN=1,1\r\n" > /dev/ttyUSB2
```

---

## 4. 检查 SIM 卡状态  

```bash
# 后台显示模块响应
cat /dev/ttyUSB2 &

# 发送指令检查 SIM 卡状态
echo -e "AT+CPIN?\r\n" > /dev/ttyUSB2

# 成功返回示例
+CPIN: READY

# 失败示例
+CME ERROR: 10
+CME ERROR: 13
```

---

## 5. 开机自动拨号脚本  

目前在开机脚本中使用以下命令实现拨号：

```bash
echo -e "AT+QCFG=\"usbnet\",1\r\n" > /dev/ttyUSB1
sleep 2
echo -e "AT+qnetdevctl=0,1,1\r\n" > /dev/ttyUSB1
sleep 2
echo -e "AT+qnetdevctl=1,1,1\r\n" > /dev/ttyUSB1
sleep 2
ifconfig usb0 up
sleep 1
udhcpc -i usb0
sleep 1
nmcli connection modify "Mobile Network" ipv4.route-metric 1000
sleep 1
nmcli connection down "Mobile Network" && sudo nmcli connection up "Mobile Network"
```

## 7. 附注  

- 模块支持通过 `/dev/ttyUSB1` 或 `/dev/ttyUSB2` 写入 AT 指令。  
- ECM 模式推荐用于 Linux 系统，默认会识别为 `usb0` 网络接口。  
- 若模块未正常拨号，请检查 SIM 卡插入、模块识别及网卡模式配置是否正确。
