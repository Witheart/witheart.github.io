## 🔌 CRPS 电源介绍

**CRPS** 全称是 **Common Redundant Power Supply**（通用冗余电源规范），是服务器领域的一种标准化电源模块规范，主要用于数据中心和高端服务器平台。

它最早由服务器厂商和开放计算组织推动制定，目的是：

- 统一服务器电源尺寸
- 支持不同功率等级互换
- 支持热插拔
- 支持冗余运行

---

## 📦 一、CRPS 是什么？

CRPS 是一种 **模块化、可热插拔的服务器电源标准**，常见于：

- 1U / 2U 机架服务器
- 数据中心节点
- 高性能计算平台
- GPU 服务器

它通常以 **1+1 冗余** 或 **N+1 冗余**方式工作。

## 🏗 二、CRPS 的核心特点

### 1️⃣ 标准化尺寸

不同厂家的 CRPS 电源模块尺寸、接口基本一致，可以互换（前提是功率等级匹配）。

典型尺寸：

- 1U 高度
- 长条形模块
- 后插式结构

### 2️⃣ 支持冗余

常见架构：

| 架构 | 说明                         |
| ---- | ---------------------------- |
| 1+1  | 两个电源，任何一个可独立供电 |
| N+1  | 多个电源，其中一个为备份     |
| N+N  | 两组完全独立电源系统         |

如果一个电源故障，系统不停机。

---

### 3️⃣ 热插拔支持

CRPS 支持：

- 不关机更换电源
- 插入自动同步输出
- 自动负载均衡

这是服务器必备特性。

---

### 4️⃣ 数字管理接口

CRPS 通常带有管理接口，例如：

- PMBus
- I2C
- SMBus

可以监控：

- 输入电压
- 输出功率
- 温度
- 电流
- 故障状态

BMC（例如基于 OpenBMC 的系统）可以通过总线读取电源状态。

---

## 🔧 三、CRPS 电源接口

CRPS 电源通常有：

### 🔌 输出接口

- 12V 主输出
- 12V Standby
- 3.3V / 5V 由主板 DC-DC 产生

### 🔍 控制信号

- PS_ON#
- PWR_OK
- SMBus
- ALERT#
- PRESENT#
- AC_OK

---

## 🖥 四、CRPS vs ATX 电源

| 对比项   | CRPS        | ATX      |
| -------- | ----------- | -------- |
| 使用场景 | 服务器      | 台式机   |
| 冗余支持 | 原生支持    | 不支持   |
| 热插拔   | 支持        | 不支持   |
| 输出类型 | 单 12V 主轨 | 多电压轨 |
| 管理接口 | 有 PMBus    | 基本无   |

---

## 🧠 五、CRPS 在服务器中的位置

在典型服务器中结构是：

AC → CRPS → 12V 母线 → 主板 DC-DC → 各个电压域

CPU、GPU、内存电压通常由主板 VRM 负责转换。
