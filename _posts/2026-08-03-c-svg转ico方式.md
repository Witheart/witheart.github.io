```bash
sudo apt install imagemagick
```

```bash
convert -background none icon.svg -define icon:auto-resize=256,128,64,48,32,16 icon.ico
```
如果系统里的 ImageMagick 是 7.0 以上的版本，把命令开头的 convert 换成 magick 就可以。
