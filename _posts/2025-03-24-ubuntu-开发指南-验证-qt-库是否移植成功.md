## 版本号查询
```sh
qmake -v
```

## 创建qt项目并编译执行
```bash
# 创建测试目录并进入
mkdir qt_test && cd qt_test

# 创建 main.cpp 文件
cat << EOF > main.cpp
#include <QApplication>
#include <QLabel>
int main(int argc, char *argv[]) {
    QApplication app(argc, argv);
    QLabel label("Qt 移植成功！");
    label.show();
    return app.exec();
}
EOF

# 生成项目文件并添加必要的配置
qmake -project
echo "QT += core gui widgets" >> qt_test.pro
echo "CONFIG += c++11" >> qt_test.pro

# 生成 Makefile 并编译项目
qmake
make

# 在桌面终端运行生成的可执行文件
./qt_test
```
