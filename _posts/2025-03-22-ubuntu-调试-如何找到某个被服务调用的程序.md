概要：本文介绍了如何通过进程查找某个被服务调用的程序，并以 4G 拨号为例，展示具体步骤。  


## 1. 以 4G 拨号为例  

### 1.1 查看进程  

使用 `ps -ef` 命令查看当前运行的进程：  

```sh
ps -ef
```

找到相关进程，例如：  

```sh
root         483       1  0 09:47 ?        00:00:00 /usr/local/bin/quectel-CM
```

### 1.2 进入服务目录  

如果该进程是由某个服务启动的，可以进入 `systemd` 服务目录：  

```sh
cd /lib/systemd/system
```

### 1.3 查找启动进程的服务  

使用 `grep` 命令搜索相关的服务配置文件：  

```sh
root@user:/lib/systemd/system# grep -irn 'quectel-CM'  ./
```

示例输出：  

```sh
./ec20.service:10:ExecStart=/usr/local/bin/quectel-CM
```

结果表明，该进程由 `ec20.service` 服务启动。
