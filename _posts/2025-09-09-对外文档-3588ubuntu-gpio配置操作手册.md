## 简介
本手册指导您如何修改3588Ubuntu系统中的GPIO方向配置，并验证修改结果。

## 操作步骤

### 第一步：定位开机脚本
1. 打开终端
2. 使用以下命令找到并编辑开机脚本：
   ```bash
   sudo nano /test/autorun.sh
   ```

### 第二步：修改GPIO方向配置
在脚本中找到GPIO配置部分，修改为以下内容：

```bash
# 设置GPIO方向（out表示输出，in表示输入）
echo out > /sys/class/gpio/gpio15/direction
echo out > /sys/class/gpio/gpio34/direction
echo in > /sys/class/gpio/gpio36/direction
echo in > /sys/class/gpio/gpio129/direction

echo out > /sys/class/gpio/gpio16/direction
echo out > /sys/class/gpio/gpio35/direction
echo in > /sys/class/gpio/gpio128/direction
echo in > /sys/class/gpio/gpio130/direction
```

### 第三步：保存并退出
1. 按 `Ctrl+O` 保存修改
2. 按 `Enter` 确认
3. 按 `Ctrl+X` 退出编辑器

## 验证修改是否成功
1. 将3588_gpio_info.sh脚本复制到系统中

2. 进入脚本所在目录：

3. 给予执行权限：
   ```bash
   chmod +x 3588_gpio_info.sh
   ```
4. 执行验证脚本：
   ```bash
   ./3588_gpio_info.sh
   ```
