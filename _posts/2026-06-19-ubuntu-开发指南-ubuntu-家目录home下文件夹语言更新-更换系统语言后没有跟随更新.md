## 问题描述

当你在 Ubuntu 中切换系统语言后，系统默认**不会**自动重命名家目录下的用户文件夹（如“桌面”、“下载”、“文档”等）。

## 这是bug吗？

这不是 Bug，而是系统的一种安全机制。这是因为很多软件的配置文件、脚本或你手动创建的快捷方式可能已经绑定了原来的绝对路径（例如 `/home/user/桌面`）。如果系统强制在后台重命名这些文件夹，会导致大量路径失效或报错。

## 🛠️ 解决方法

### 通过终端唤起更新弹窗（推荐，最直观）

如果你在使用图形界面，可以通过终端命令手动唤起系统的“更新标准文件夹名称”对话框。

1. 打开终端（快捷键 `Ctrl` + `Alt` + `T`）。
2. 确保系统当前语言环境变量是英文（如果你已经切换到了英文），输入以下命令并回车：

```bash
export LANG=en_US.UTF-8

```

3. 接着输入以下命令唤起更新程序：

```bash
xdg-user-dirs-gtk-update

```

4. 此时会弹出一个对话框，询问你是否要将标准文件夹更新为当前语言。点击 **"Update Names"（更新名称）** 即可。

---

## 注意

使用上述方法更新路径后，家目录下可能会出现**中英双份**文件夹的情况（例如同时存在“桌面”和“Desktop”）。这是正常的系统保护行为：

- 系统已经将默认路径指向了新建的英文文件夹（如 `Desktop`）。
- 原来的中文文件夹（如 `桌面`）变成了一个普通文件夹被保留了下来。

**需要做什么：**

1. 打开文件管理器，把原来中文文件夹（如“桌面”、“下载”）里的个人文件，全部手动**剪切**并**粘贴**到新的英文文件夹（“Desktop”、“Downloads”）中。
2. 确认中文文件夹已经完全清空后，直接将这些空的中文文件夹**删除**即可。
