## grep 搜索文本内容
1. 打开终端，进入包含`./device`目录的上级目录。
2. 执行以下命令：
   ```bash
   grep -rnw './device' -e 'DEVICE_MANIFEST_FILE'
   ```
   - `-r` 或 `--recursive`：递归搜索子目录。
   - `-n` 或 `--line-number`：显示匹配行的行号。
   - `-w` 或 `--word-regexp`：仅匹配整个单词，避免部分匹配。
   - `'./device'`：要搜索的目录路径。
   - `-e 'DEVICE_MANIFEST_FILE'`：指定要搜索的字符串。

3. 其他参数
- 排除特定目录：例如忽略`.git`目录：
  ```bash
  grep -rnw --exclude-dir=.git './device' -e 'DEVICE_MANIFEST_FILE'
  ```
- 不区分大小写：添加`-i`参数（如不确定字段大小写）：
  ```bash
  grep -rni './device' -e 'DEVICE_MANIFEST_FILE'
  ```

## find 搜索文件属性（文件名等）
以查找 Sunlogin 文件为例

1. find  
   基础文件搜索命令，支持通过名称、类型、时间戳等 50+ 条件进行筛选

2. /  
   搜索起始路径设置为根目录，将对整个文件系统进行遍历（包含外接存储）

3. -iname  
   大小写不敏感的匹配模式：
   ```bash
   # 同时匹配 SunLogin、sunlogin、SUNLOGIN
   find /home -iname "sunlogin*"
   ```

4. "*sunlogin*"  
   通配符组合实现模糊搜索：
   - 星号* 匹配任意长度字符

   - 问号? 匹配单个字符

   - [abc] 匹配指定字符集
