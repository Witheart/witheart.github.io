一般不要做更改用户名的操作，因为如果配置过依赖用户名或者用户组的操作，改名字要把这些操作都变更了，十分的麻烦，本指南比较适用于还没怎么配置过的系统。


在 Ubuntu 中更改用户名需要同时修改 **用户账户名** 和 **家目录名称**（可选），操作如下：

### 步骤 1️⃣：准备环境
- **退出所有该用户的进程**  
  确保目标用户未登录，且没有正在运行的进程：
  ```bash
  sudo pkill -u 旧用户名   # 结束该用户所有进程
  sudo usermod -L 旧用户名  # 临时锁定账户（可选）
  ```

- **使用 root 权限操作**  
  切换到另一个管理员账户（如 `root`），或全程使用 `sudo`。

---

### 步骤 2️⃣：修改用户名
```bash
sudo usermod -l 新用户名 旧用户名
```
- `-l`：更改登录名（用户账户名）。

---

### 步骤 3️⃣：修改家目录名（可选但推荐）（必须先完成步骤 2）
```bash
sudo usermod -d /home/新用户名 -m 新用户名
```
- `-d`：指定新家目录路径。
- `-m`：自动将旧家目录内容移动到新目录。

> ⚠️ 注意：如果旧家目录非 `/home/旧用户名`，需手动迁移文件。

---

### 步骤 4️⃣：修改用户组名（与旧用户名同名时需改）
```bash
sudo groupmod -n 新用户名 旧用户名
```
- `-n`：更改用户组名（仅当存在和旧用户名同名的组时需操作）。

---

### 步骤 5️⃣：更新文件所有权
```bash
sudo chown -R 新用户名:新用户名 /home/新用户名
```
- 确保新家目录所有文件归属正确。

---

### 步骤 6️⃣：更新相关配置
检查以下文件，手动替换旧用户名：
- **Sudoers 文件**：  
  ```bash
  sudo visudo   # 检查 /etc/sudoers
  ```
- **Cron 任务**：  
  ```bash
  sudo crontab -u 新用户名 -e   # 检查定时任务
  ```
- **配置文件**：  
  检查 `~/.bashrc`、`~/.profile`、`/etc/passwd` 中是否有残留路径。

- 书签残留
~/.config/gtk-3.0/bookmarks下可能会有文件管理器残留的书签。

---

### 步骤 7️⃣：重启系统（推荐）
```bash
sudo reboot
```
重启确保所有服务使用新用户名加载。


### 补充：
如果不是使用更名的方式，而是使用新建用户并迁移的方式，需要查看原来的用户属于什么组，使用groups查看，新用户要加入同样的组。
