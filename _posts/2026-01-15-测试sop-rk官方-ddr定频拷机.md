概要：本文介绍在 RK 平台上进行 DDR 定频拷机测试的具体步骤，包括设置固定频率、确认频率、评估可用内存以及使用 stressapptest 进行长时间拷机测试的方法。


## 1. 启动持续运行的应用  

开启 glmark2，或其他有 GPU 或 NPU 参与的能持续运行的应用程序：

```bash
glmark2-es2 --run-forever
```

---

## 2. 查看与设置 DDR 频率  

### 2.1 查看当前支持的频率  

```bash
cat /sys/class/devfreq/dmc/available_frequencies
```

### 2.2 设置为指定频率  

使用脚本设置频率：

```bash
./ddr_freq_scaling.sh 2112000000
```

该命令等效于以下手动设置：

```bash
sudo su
echo userspace > /sys/class/devfreq/dmc/governor
echo 2112000000 > /sys/class/devfreq/dmc/userspace/set_freq
```

---

## 3. 确认频率设置是否生效  

通过 log 确认当前频率：

```bash
cat /sys/class/devfreq/dmc/cur_freq
```

---

## 4. 评估可用内存空间  

获取可用于做 DDR 测试的空闲内存空间大小：

```bash
free -m
```

一般选取可用于启动新应用程序的内存量（即 available 值）的 90% 用于做 DDR 测试。

---

## 5. 进行 stressapptest 拷机测试  

使用 stressapptest 进行拷机，推荐拷机时间为 12 小时以上，内存量请手动更改：

```bash
stressapptest -s 43200 -i 4 -C 4 -W --stop_on_errors -M 3084
```
