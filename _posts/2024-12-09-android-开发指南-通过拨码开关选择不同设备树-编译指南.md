## 只进行多设备树的编译并打包进resource.img
```bash
./build_hw.sh -m
```

## 进行多设备树的编译并得到update.img
```bash
./build_hw.sh -mu
```

## 注意
如果要得到含多设备树update.img，即使提前使用-m参数得到了包含多设备树的resource.img，也不能单独使用-u参数，否则得到的是错误的update.img镜像（包含两个rk-kernel.dtb），具体原理见《拨码开关选择不同设备树——编译脚本的修改》。
