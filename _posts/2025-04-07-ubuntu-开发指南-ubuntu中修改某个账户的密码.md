概要：本文介绍了在Ubuntu系统中修改某个账户密码的两种方法，包括使用`passwd`命令修改其他用户密码和修改当前登录用户的密码。


## 1. 使用 `passwd` 命令（需管理员权限）

### 1.1 打开终端  
- 使用快捷键 `Ctrl+Alt+T` 打开终端。

### 1.2 修改其他用户的密码  
- 需要使用 `sudo` 权限来修改其他用户的密码，命令如下：
  ```bash
  sudo passwd 用户名
  ```
  例如，修改用户 `tom` 的密码：
  ```bash
  sudo passwd tom
  ```

### 1.3 输入管理员密码  
- 执行 `sudo` 命令时，需要输入当前用户的密码。

### 1.4 设置新密码  
- 按提示输入两次新密码（输入时不会显示字符，直接键入即可）。

---

## 2. 修改自己的密码（无需 `sudo`）

### 2.1 直接运行 `passwd` 命令  
- 如果修改当前登录账户的密码，直接运行以下命令：
  ```bash
  passwd
  ```

### 2.2 按提示操作  
- 按提示输入当前密码和新密码即可完成修改。
